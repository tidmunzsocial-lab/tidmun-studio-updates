# การติดตั้ง “ติดมันส์ สตูดิโอ” บนเครื่องอื่น

ระบบตรวจและแก้บัคต้องทำงานจากสภาพจริงของ **เครื่องที่กำลังใช้งาน** เสมอ ห้ามอิงชื่อผู้ใช้ `Apinan`, ไดรฟ์ `C:` หรือโปรแกรมที่ติดตั้งอยู่เฉพาะเครื่องผู้พัฒนา

1. คัดลอกโฟลเดอร์ `Project snapgen.ai` ไปทั้งโฟลเดอร์ ห้ามคัดลอกเฉพาะไฟล์ `.bat`
2. ครั้งแรกให้เปิด `setup_and_run.bat` เพื่อเตรียม Python 3.12 และ environment ของโปรแกรม ตัวติดตั้งจะสร้าง `ติดมันส์ สตูดิโอ.lnk` ให้เปิดครั้งต่อไปโดยไม่ต้องพึ่ง file association ของ `.py`
3. ในโปรแกรมเปิด Settings แล้วกด `🩺 ตรวจและแก้บัค` ระบบจะตรวจ/ติดตั้ง Python packages, FFmpeg, curl และ Tailscale ให้อัตโนมัติ
4. Bridge ดาวน์โหลดด้วย ZIP ได้ จึงไม่บังคับว่าต้องมี Git, uv หรือ winget
5. Account/cookies และ API keys เป็นข้อมูลเฉพาะผู้ใช้ แต่ละเครื่องต้องเพิ่ม Account ของตัวเองใน Bridge Manager ห้ามแจกไฟล์ตั้งค่าที่มี token/cookies ของเครื่องอื่น
6. ทุกเครื่องใช้ Bridge ภายในเครื่องตัวเองที่ `127.0.0.1:8000` และเพิ่ม ChatGPT Account ของเครื่องนั้นเอง
7. Tailscale ยังใช้บัญชีเดียวกันสำหรับตรวจสถานะเครือข่าย แต่ไม่ใช้เป็นที่อยู่ Bridge กลาง
8. หลังติดตั้งครั้งแรก เปิดด้วย `ติดมันส์ สตูดิโอ.lnk` หรือ `เปิดโปรแกรม.cmd` ได้ทันที หากดับเบิลคลิก `.py` ไม่ได้ แปลว่า Windows เครื่องนั้นไม่ได้ผูกนามสกุล `.py` กับ Python ซึ่งไม่กระทบ Shortcut นี้

ถ้าซ่อมไม่ครบ รายงานจะอยู่ที่ `snapgen_data/logs/system_repair.json` และจะแสดงสาเหตุจริงในหน้าต่างซ่อม
